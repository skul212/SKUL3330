A professional, reliable terminal UI for browsing **600+ AI providers** and **1100+ models**.

## Features

- Full-screen terminal UI with keyboard navigation
- Provider & model browsing with pagination
- Live filtering/search
- Model details: context window, pricing, modalities
- Stats overview
- Zero runtime dependencies (pure Node.js)

## Install & Run

```bash
git clone <repo>
cd app
npm start
```

Or link globally:

```bash
npm link
aix
```

## Controls

| Key | Action |
|---|---|
| ↑/↓ | Navigate |
| Enter | Select / open details |
| Type | Filter list |
| Backspace | Delete filter char |
| PgUp/PgDn | Change page |
| Esc | Back |
| q / Ctrl+C | Quit |
